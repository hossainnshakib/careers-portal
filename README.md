# Careers Portal — Agent Kit

এই ফোল্ডারটাই আপনার কোডিং এজেন্টের "প্রজেক্ট মেমরি"। `G:\career`-এর ভেতরে এমনভাবে রাখুন যাতে `AGENTS.md`, `docs/`, `prompts/`, `design/` সরাসরি `G:\career`-এর নিচে থাকে।

## কীভাবে চালাবেন
1. জিপ extract করুন `G:\career`-এ।
2. টার্মিনাল খুলুন `G:\career`-এ এবং এজেন্ট চালু করুন (Claude Code হলে `claude`)। Claude Code `CLAUDE.md` পড়ে (সেটা `AGENTS.md` ইম্পোর্ট করে), অন্য এজেন্ট (Cursor ইত্যাদি) সরাসরি `AGENTS.md` পড়ে।
3. প্রথমে `prompts/00-master-kickoff.md`-এর **PROMPT** অংশ পেস্ট করুন। এটা কোড লেখাবে না, শুধু সব ডক পড়ে বোঝাপড়া, সমস্যা, প্রশ্ন আর পরিকল্পনা রিপোর্ট করবে।
4. তার প্রশ্নের উত্তর দিন, তারপর ক্রমে একটা একটা phase চালান: `01` → `02` → `03` → `04` → `05` → `06`। প্রতিটি ফাইলের ওপরে "Owner checklist" আছে, মানে ওই phase শুরুর আগে আপনার কী করতে হবে।
5. প্রতিটি phase-এ এজেন্ট প্রথমে **plan** দেবে। পড়ে "go" বললে তবেই কোড লিখবে। শেষে রিপোর্ট দেবে, আপনি নিজে একবার চালিয়ে দেখে মার্জ করুন, তারপর পরের phase।

## ফাইলগুলো
- `AGENTS.md` — এজেন্টের নিয়ম (স্ট্যাক, স্কোপ, নিরাপত্তা, কাজের ধরন)
- `docs/PRODUCT.md`, `ARCHITECTURE.md`, `SCHEMA.md`, `SEED_DATA.md`, `DESIGN.md` — সিদ্ধান্তগুলো
- `prompts/` — মাস্টার প্রম্পট ও ছয়টি phase-এর প্রম্পট
- `design/logos/` — আপনার আটটি লোগো, স্লাগ নামে
- `.env.example` — কী কী এনভায়রনমেন্ট ভ্যারিয়েবল লাগবে (আসল মান শুধু `.env.local`-এ, কখনো commit নয়)
